### Notes on how these were published

X has no available API credentials for this account, so every post went out
through a real browser session (Playwright Firefox against a copy of the
signed-in profile). Three things that cost real time and are worth recording:

- **One fresh browser per post.** A long-lived session hits an
  "Unlock more on X" interstitial and then silently refuses to post.
- **Videos must be re-encoded.** X failed the original 22–32 MB files with
  "Upload failed due to network problems. Check your connection and then
  resume." The 3.8–5.3 MB copies upload cleanly.
- **Text must be inserted, not typed.** `keyboard.type()` drops the en dash in
  "1–5" and reorders emoji; `keyboard.insert_text()` preserves the code points.

Pinning is also not available through the web UI's own menu in this session —
the click registered but no request was ever sent. The `PinTweet` /
`UnpinTweet` GraphQL mutations, called with the page's own session, do work.
